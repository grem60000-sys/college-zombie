# Collège Zombie — Opération Sauvetage

Jeu de révision pour un élève de 5e : choisir une matière et des notions, explorer l'établissement, libérer 12 camarades et vaincre 5 boss en répondant à des questions.

Jouer : https://grem60000-sys.github.io/college-zombie/

Tout le jeu tient dans `index.html` (aucune dépendance externe).
