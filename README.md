# Collège Zombie — Opération Sauvetage

Jeu de révision pour un élève de 5e : choisir une matière et des notions, explorer l'établissement en 3D, libérer 12 camarades et vaincre 5 boss (Clown démoniaque, Frankenstein, Dracula, Loup-Garou, Diable) en répondant à des questions.

Jouer : https://grem60000-sys.github.io/college-zombie/

- `index.html` : version 3D (personnages en blocs, caméra à la troisième personne). Tout tient dans ce fichier, moteur three.js compris : aucune dépendance externe.
- `classique.html` : l'ancienne version 2D, pour les appareils qui n'affichent pas la 3D.

Commandes
- Téléphone / tablette : pouce gauche pour se déplacer, pouce droit pour tourner la caméra (double-tape pour la remettre derrière soi), gros bouton rouge pour tirer. Le tir automatique vise tout seul.
- Ordinateur : ZQSD / WASD / flèches, souris pour viser, clic gauche pour tirer, clic droit maintenu (ou glisser à deux doigts) pour tourner la caméra, molette pour zoomer.
